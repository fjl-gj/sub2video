# 资产 · 页面流程

路由：`/app/assets`  
组件：`frontend/src/pages/client/AssetsPage.vue`

---

## 这页是干什么的

以**作品**为单位的工程文件空间：管理素材、成片和目录结构。

用户来这里**新建/进入作品、浏览文件夹、上传素材、删除单个文件**；作品级删除走回收站。

**不做的事：** 不提交生成任务（去创作）；不永久删除作品（去回收站）；不展示 OSS / 供应商路径。

---

## 核心对象

```
作品（工程）
├── 资产/
│   ├── 人物
│   ├── 场景
│   ├── 道具
│   └── 素材
└── 视频/
    └── 正片镜头（默认子目录，可扩展）
```

新建作品一律套用上述**标准模板**。系统根目录（`资产`、`视频` 及固定子目录）不可删除，仅可往里放文件。

## 两层视图

### 层 1：作品列表（`inside = false`）

| 区域 | 内容 |
| --- | --- |
| 页头 | 标题「资产」+「新建作品」 |
| 存储条 | 已用 / 配额 GB、进度条、文件数、作品数 |
| 作品卡片 | 名称、描述、创建时间、文件数；徽章「默认」「当前作品」 |
| 操作 | **进入作品** · **移入回收站**（默认作品不可移入） |

**新建作品：** 输入名称 →「按模板创建」→ 自动成为**当前作品**并进入层 2。

### 层 2：作品内浏览（`inside = true`）

| 区域 | 内容 |
| --- | --- |
| 页头 | 作品名 +「返回作品列表」+「上传素材」 |
| 面包屑 | 作品名 / 子目录… 可点击回退 |
| 工具栏 | 网格 / 列表切换 · 当前目录搜索 |
| 内容 | 文件夹卡片 + 文件卡片（图片 / 视频 / 音频） |

**进入某作品时**会同步设为 `currentProject`（创作「从资产选图」、任务「保存到作品」都用它）。

---

## 用户会怎么走

```
资产
  │
  ├─ 作品列表
  │     ├─ 新建作品 → 进入新作品根目录
  │     ├─ 进入作品 → 浏览 资产/视频 树
  │     └─ 移入回收站 → 确认 → 作品进回收站
  │
  └─ 作品内
        ├─ 点文件夹 → 深入子目录
        ├─ 面包屑 → 回上层
        ├─ 上传素材 → 写入当前目录（根目录默认 资产/素材）
        ├─ 删单个文件 → 从作品中移除
        └─ 返回作品列表
```

---

## 上传规则（原型）

| 情况 | 上传目标目录 |
| --- | --- |
| 在作品根目录点上传 | `资产/素材` |
| 在某个子目录内点上传 | 当前路径 |

上传为模拟：生成一条本地 mock 文件记录，更新容量统计。

---

## 和其他页面的关系

| 页面 | 关系 |
| --- | --- |
| **创作** | 「从资产选择」读取**当前作品**下的图片 |
| **任务** | 「保存到当前作品」写入 `视频/正片镜头` |
| **回收站** | 移出的作品在此恢复或彻底删除 |
| **首页概览** | 展示空间占用、文件数（汇总） |

```
任务 ──保存成片──► 资产（当前作品 / 视频）
创作 ──选图──────► 资产（当前作品 / 图片）
资产 ──移出作品──► 回收站
```

## 当前作品

- 全局只有一个 `currentProject`
- 新建作品、进入作品、从回收站恢复（且无当前作品时）会更新它
- 作品列表显示 **「当前作品」** 绿色徽章

---

## 当前实现缺口

1. 不能新建自定义子文件夹（仅模板目录）。  
2. 文件不能预览 / 下载，删除无二次确认。  
3. 列表视图与网格信息相同，无批量操作。  
4. 默认作品 `default作品` 不可进回收站，但 UI 外仍应注意勿删。  
5. 素材有效期（7 天 / 30 天）产品方案有述，页面未展示。
