# 页面流程文档

本目录描述**用户在页面上的操作流程**：从哪进、看见什么、能点什么、跳到哪、有哪些分支与空态。

与 `docs/api/` 的区别：

| | `docs/flows/` | `docs/api/` |
| --- | --- | --- |
| 视角 | 产品 / 交互 / 页面状态 | 后端接口与数据结构 |
| 读者 | 产品、设计、前后端对齐业务 | 后台设计与联调 |
| 内容 | 流程图、操作路径、页面分区 | REST 路径、JSON 字段 |
