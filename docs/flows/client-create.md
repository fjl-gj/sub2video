# 创作 · 页面流程

路由：`/app/create`  
组件：`frontend/src/pages/client/CreatePage.vue`

---

## 这页是干什么的

按**工作流模式**配置输入与参数，**提交一次视频生成任务**。

**不做的事：** 不看任务进度、不管作品目录、不充值（余额不足只 Toast）。

---

## 三种顶层模式

| 模式 | 状态 | 子形态 / 输入 |
| --- | --- | --- |
| **图生视频** | 可用 | **首尾帧**：首帧（必填）+ 尾帧（可选）<br>**多图参考**：1～3 张参考图（至少 1 张） |
| **文生视频** | 即将开放 | 仅画面描述，无素材上传 |
| **视频生视频** | 即将开放 | 参考视频 + 可选描述 |

每种模式只展示**该模式需要的输入区**；文生 / 视频生目前 UI 已占位，提交未开放。

## 页面上有什么（图生视频 · 当前可用路径）

### ① 页头

标题「创作」+ 钱包余额角标。

### ② 模式选择

三张卡片：图生视频 / 文生视频 / 视频生视频。

### ③ 图生子模式（分段）

首尾帧 · 多图参考。

### ④ 输入素材

| 子模式 | 内容 |
| --- | --- |
| 首尾帧 | 首帧、尾帧各一块：上传或从**当前作品**资产选图 |
| 多图参考 | 最多 3 个参考图位，上传或从资产选 |

> 已去掉「最多 5 张免费」等与产品无关的文案。

### ⑤ 画面描述（主输入区）

- 大文本框（约 9 行），占页面主要篇幅  
- 快捷标签：电影感 / 缓慢推进 / 自然光 / 细节丰富  

### ⑥ 生成设置（横向一排）

| 控件 | 说明 |
| --- | --- |
| 画面比例 | 下拉：16:9 / 9:16 / 1:1 |
| 视频时长 | 数字输入，**1～15 秒**自定义 |
| 预计费用 | ¥0.50/秒 × 时长，实时显示 |
| 提交 | 「提交生成任务」 |

**无作品标题字段。** 任务名自动生成：

```text
图生·首尾帧 0901 2031 #5
图生·多图   0901 2031 #6
文生        …（开放后）
```

格式：`模式[·子形态] MMdd HHmm #当日序号`

底部说明：提交预扣费，失败退回钱包。

## 用户怎么走（图生）

```
选「图生视频」
  → 选「首尾帧」或「多图参考」
  → 上传 / 从资产选图（首尾帧须先有首帧）
  → 写画面描述（广场可预填）
  → 横排：比例 · 时长 · 看费用
  → 提交
        ├─ 余额够 → 预扣 → 任务排队 → 跳转任务页
        └─ 不够 / 未选图 → Toast，留本页
```

## 草稿要不要单独做？

**首期：无「保存草稿」按钮，但有本机静默暂存。**

| 做法 | 说明 |
| --- | --- |
| 广场带入 | `draftPrompt` 进创作页；**优先于** localStorage 里旧的描述 |
| 静默暂存 | `localStorage` 自动保存模式、素材位、描述、比例、时长；约 320ms 防抖 |
| 提交成功 | 清除 localStorage 草稿 + `draftPrompt` |
| 显式草稿菜单 | 暂不做 |

资产引用只存 `assetId`（不存文件本体）；`picking` 展开状态不持久化。

## 当前实现缺口

1. 上传仍为模拟，未接真实 OSS。  
2. 文生 / 视频生仅 UI 占位。  
3. 比例、时长写入任务展示，后端联调时再固化价格快照。  
4. 余额不足无「去充值」快捷入口。  
5. 余额不足无「去充值」快捷入口。  
6. localStorage 草稿仅存本机，换设备/清缓存会丢失；上传文件本身无法恢复，仅记住「已选」状态与资产 ID。
