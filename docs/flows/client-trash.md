# 回收站 · 页面流程

路由：`/app/trash`  
组件：`frontend/src/pages/client/TrashPage.vue`

---

## 这页是干什么的

存放从**资产页移出**的作品工程，支持**恢复**或**彻底删除**。

**不做的事：** 不管理单个文件；任务队列里的临时结果不进这里；不能从这里直接编辑作品内容。

---

## 怎么进入这页

| 入口 | 说明 |
| --- | --- |
| 侧栏「回收站」 | 主入口 |

---

## 页面上有什么

### ① 页头

标题「回收站」+ 说明：移出的作品先到这里，可恢复或彻底删除。

### ② 作品卡片列表

每张卡：

| 字段 | 说明 |
| --- | --- |
| 名称 / 描述 | 作品信息 |
| 元信息 | 移入时间 · 文件数 |
| **恢复** | 作品回到资产列表，可再次进入 |
| **彻底删除** | 二次确认后永久移除，不可恢复 |

### ③ 空态

无作品时：「回收站是空的」。

---

## 用户会怎么走

```
回收站
  │
  ├─ 恢复 → 作品回到资产页列表
  │         （若当时没有当前作品，恢复项会成为当前作品）
  │
  └─ 彻底删除 → 确认弹窗 → 从系统移除
```

资产页移入路径：

```
资产 · 作品列表 ──移入回收站──► 回收站
```

---

## 和资产页的分工

| 操作 | 资产页 | 回收站 |
| --- | --- | --- |
| 删单个文件 | ✅ | ❌ |
| 移出整个作品 | ✅（软删除） | 存放 |
| 恢复作品 | ❌ | ✅ |
| 永久删除作品 | ❌ | ✅ |

**默认作品**（`default作品`）在资产页**不能**移入回收站。

---

## 当前实现缺口

1. 无「清空回收站」批量操作。  
2. 无自动清理策略（如 30 天后永久删除）的 UI 提示。  
3. 恢复后不会自动打开作品内目录，只回到资产列表。
