# 广场 · 页面流程

路由：`/app/garden`  
组件：`frontend/src/pages/client/GardenPage.vue`  
卡片：`frontend/src/features/garden/SceneCard.vue`

---

## 这页是干什么的

浏览**官方场景模板**（镜头结构 + 预设提示词），看中后**一键带到创作页**。

**只负责「找灵感、带文案」**，不提交任务、不上传素材、不扣费。

---

## 怎么进入这页

| 入口 | 说明 |
| --- | --- |
| 侧栏「广场」 | 主入口 |

> 首页概览目前没有直达广场的按钮（产品文案提过「灵感入口」，页面上未做）。

---

## 页面上有什么（从上到下）

### ① 页头

| 元素 | 内容 |
| --- | --- |
| 标题 | 广场 |

无副标题、无页头操作按钮。

### ② 筛选栏

| 控件 | 作用 |
| --- | --- |
| 分类分段 | 全部 / 电影感 / 自然 / 商业 / 生活 / 叙事 / 艺术 |
| 比例分段 | 全部 / 横屏（16:9）/ 竖屏（9:16）/ 方形（1:1） |
| 搜索框 | 按场景**标题 + 描述**过滤（前端即时筛选） |

切换分类、比例或搜索时，列表回到首批并重置滚动加载计数。

### ③ 场景瀑布流

布局：**CSS 多列瀑布流**（手机 1 列、平板 2 列、桌面 3 列）。每张卡按真实 `aspectRatio` 定高，横竖方形可混排。

每张卡片（`SceneCard`）包含：

| 区域 | 内容 |
| --- | --- |
| 预览区 | 示例视频 + 封面；**鼠标悬停自动静音循环播放**，离开恢复封面 |
| 角标 | 分类、比例、分辨率 · 时长 |
| 标题 + 描述 | 描述最多两行 |
| 操作 | **「套用」** 按钮 |

当前 mock 共 **18 个**场景模板，首批加载 12 条，**向下滚动自动加载更多**（非页码分页）。

## 用户在这页会怎么走

```
进入广场
    │
    ├─ 可选：切换分类
    ├─ 可选：输入关键词搜索
    │
    ├─ 浏览场景卡片
    │
    └─ 点击某张卡的「套用」
           ├─ 把「标题，描述」写入 draftPrompt
           ├─ Toast：已套用「xxx」
           └─ 跳转创作页（画面描述已预填）
                 └─ 用户还需：选首帧图 → 调参数 → 提交
```

**广场本身没有「提交」或「收藏」**，唯一出口是 **套用 → 创作**。

---

## 套用时具体发生什么

```
draftPrompt = "{场景标题}，{场景描述}"
例如：雨夜霓虹漫步，潮湿街巷、霓虹反射和稳定跟拍，适合人物氛围片。
```

- **会带过去：** 画面描述（prompt 文本）  
- **不会带过去：** 参考图、比例、时长、工作流选择（创作页各自默认）

---

## 和其他页面的关系

| 页面 | 关系 |
| --- | --- |
| **创作** | 套用后唯一跳转目标；prompt 预填 |
| 首页概览 | 无直达入口（可补） |
| 任务 / 资产 / 钱包 | 无直接关系 |

主链路位置：

```
广场 ──套用──► 创作 ──提交──► 任务 ──保存──► 资产
```

## 空态与边界

| 情况 | 表现 |
| --- | --- |
| 搜索无结果 | 网格为空，**无专门空态文案** |
| 某分类下无模板 | 同上（当前 mock 每类至少有一条） |

---

## 当前实现缺口（若要改产品可讨论）

1. 示例视频为 MDN 占位素材，上线后需替换为官方精选成片。  
2. 套用时不带比例 / 时长到创作页（仅 prompt）。  
3. 悬停播放在移动端无效（仅显示封面与播放图标）。  
4. 无详情弹层（大播放器 + 完整描述），目前卡片即全部信息。  
5. 场景数据写死在 `mock.ts`，滚动加载为前端切片，后端需 `cursor` 或 `page` 接口。  
6. 无「收藏场景」能力。  
7. 管理端「场景模板」菜单产品方案里标为**暂缓**，与广场未打通。
