# 首页概览 · 页面流程

路由：`/app/overview`  
组件：`frontend/src/pages/client/OverviewPage.vue`

---

## 这页是干什么的

登录后的**默认落地页**。  
用户来这里**看一眼账户和任务状态**，然后决定去创作、看任务或充值。  

**不做的事：** 不在这里填 prompt、不上传素材、不管理作品文件、不提交任务。

---

## 怎么进入这页

| 入口 | 说明 |
| --- | --- |
| 登录成功 | 默认跳到本页 |
| 侧栏「首页概览」 | |
| 顶栏 Logo | 点击回到本页 |

---

## 页面上有什么（从上到下）

### ① 页头

| 元素 | 内容 | 可点击 |
| --- | --- | --- |
| 标题 | 欢迎回来，李维工作室 | 否 |
| 按钮 | 查看任务队列 | 是 → 任务页 |
| 按钮 | 新建生成任务 | 是 → 创作页 |

### ② 五张指标卡（横排）

| 卡片 | 展示什么 | 副文案 | 点击 |
| --- | --- | --- | --- |
| 累计支出 | ¥ 148.00 | 本月消耗 ¥36.00 | 无 |
| 可用余额 | 当前钱包余额 | 立即充值 → | → 钱包页 |
| 每秒视频均价 | ¥ 0.20 /s | 768P / 1080P 按秒计 | 无 |
| 空间资源占用 | 已用 / 配额 GB | 已保存 N 个文件 | 无 |
| 进行中的任务 | 活跃任务数量 | 查看队列 → | → 任务页 |

> 说明：累计支出、本月消耗、秒价目前是页面写死的数；余额、空间、任务数来自系统数据。

### ③ 进行中的任务（一块大卡）

- **有任务时：** 只展示**第一条**排队中或生成中的任务（标题、预扣金额、工作流、进度条）。
- **没有时：** 文案「当前没有进行中的任务」。
- 右上角「查看全部 →」→ 任务页。

### ④ 最近完成任务（最多 2 条）

每条卡片：缩略图、文件名、分辨率·时长·费用、状态「生成成功」、**下载**按钮。  
区块标题旁「进入任务 →」→ 任务页。

## 用户在这页会怎么走

```
进入首页概览
    │
    ├─ 想继续创作 ──────────► 点「新建生成任务」──► 创作页
    │
    ├─ 想看全部任务 ────────► 点「查看任务队列」或「查看全部」──► 任务页
    │
    ├─ 余额不够想充值 ──────► 点可用余额卡「立即充值」──► 钱包页
    │
    ├─ 关心正在跑的任务 ────► 看中部的进行中任务卡片（仅首条）
    │                         或点「查看全部」去任务页看完整列表
    │
    └─ 想拿刚做好的视频 ────► 在「最近完成任务」点「下载」
                              或「进入任务」去任务页操作（保存到作品等）
```

## 每个操作跳到哪里

| 用户点击 | 跳转到 |
| --- | --- |
| 查看任务队列 | `/app/works` |
| 新建生成任务 | `/app/create` |
| 立即充值 | `/app/wallet` |
| 查看队列 / 查看全部 / 进入任务 | `/app/works` |
| 下载（最近完成卡片） | 下载成片（原型仅提示，未真下） |

---

## 空态

| 情况 | 页面表现 |
| --- | --- |
| 没有进行中任务 | 中部大卡显示「当前没有进行中的任务」；指标卡「进行中任务」显示 0 |
| 没有已完成任务 | 「最近完成任务」区域为空（当前 mock 里通常有 2 条） |

---

## 和其他页面的关系

| 关联 | 说明 |
| --- | --- |
| 侧栏「任务」角标 | 数字 = 排队中 + 生成中，和指标卡「进行中任务」一致 |
| 顶栏余额 | 和指标卡「可用余额」是同一笔钱 |
| 广场 | 产品文案提过「灵感入口」，**当前页没有**直达广场的按钮 |
| 资产 | 空间占用、文件数与资产页作品文件相关，但本页不能进资产目录 |

---

## 当前实现缺口（若要改产品可讨论）

1. 累计支出 / 本月消耗 / 秒价 — 写死，未接真实账单。
2. 最近完成只有「下载」，没有「保存到作品」（保存只在任务页）。
3. 无广场 / 灵感入口。
4. 进行中任务只展示 1 条，多条要去任务页。
