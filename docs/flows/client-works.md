# 任务 · 页面流程

路由：`/app/works`  
组件：`frontend/src/pages/client/WorksPage.vue`  
侧栏菜单名：**任务**

---

## 这页是干什么的

查看和管理**所有视频生成任务**：排队、进行中、已完成、失败。

用户来这里**看进度、终止并退款、重试失败任务、下载或保存结果**。

**不做的事：** 不在这里配置 prompt 或上传素材（去创作页）；不管理作品目录结构（去资产页）。

---

## 怎么进入这页

| 入口 | 说明 |
| --- | --- |
| 侧栏「任务」 | 主入口；有进行中任务时显示数字角标（排队中 + 生成中） |
| 首页概览 | 「查看任务队列」按钮；指标卡「进行中的任务」 |
| 创作页提交成功 | 跳转本页（见创作流程） |

---

## 页面上有什么（从上到下）

### ① 页头

| 元素 | 内容 | 可点击 |
| --- | --- | --- |
| 标题 | 任务 | 否 |
| 说明 | 所有生成中的任务和已完成结果都在这里… | 否 |
| 按钮 | 新建创作 | 是 → 创作页 |

### ② 状态筛选（分段控件）

| 选项 | 作用 |
| --- | --- |
| 全部 | 不过滤 |
| 排队中 | 仅 `排队中` |
| 生成中 | 仅 `生成中`（角标旁显示进度 %） |
| 已完成 | 仅 `已完成` |
| 失败 | 仅 `失败` |

每个分段右侧显示**该状态任务数量**。切换筛选时回到第 1 页。

### ③ 任务列表

**桌面端：** 表格  
**移动端：** 卡片列表（`MobileRecordCard`）

每行 / 每张卡展示：

| 字段 | 说明 |
| --- | --- |
| 缩略图 + 标题 | 任务名 |
| 任务 ID | 等宽字体，如 `tsk_88921` |
| 工作流 | 如 `H3 图生视频` |
| 状态 | 徽章；生成中附带 `progress%` |
| 参数 | 分辨率 · 时长 |
| 费用 | 预扣金额 |
| 时间 | 相对时间文案 |

### ④ 分页

底部分页器，每页 **10** 条（`PAGE_SIZE`）。筛选结果为空时不显示分页。

### ⑤ 空态

当前筛选下无任务时，显示「暂无符合条件的任务」。

---

## 按状态可做的操作

| 状态 | 可用操作 | 结果 |
| --- | --- | --- |
| **失败** | 重新生成 | 状态改回 `排队中`，**不重复扣费** |
| **排队中 / 生成中** | 终止任务并退款 | 确认弹窗 → 状态改 `失败`，预扣金额退回钱包 |
| **已完成** | 下载结果 | Toast 模拟下载（原型） |
| **已完成** | 保存到当前作品 | 写入当前作品 `视频 / 正片镜头`，生成 `.mp4` 文件项 |
| **已完成** | 已保存过 | 按钮文案变「已保存到作品」，再次点击提示已保存 |
| **任意** | 查看详情 | Toast 展示 ID / 工作流 / 分辨率（原型，无详情页） |

终止确认弹窗文案：预扣金额将**全额退回钱包**。

## 用户在这页会怎么走

```
进入任务页
    │
    ├─ 可选：按状态筛选
    ├─ 浏览列表 / 翻页
    │
    ├─ 进行中 ──► 终止并退款？──► 确认 ──► 失败 + 钱包退回
    │
    ├─ 失败 ──► 重新生成 ──► 回到排队中
    │
    ├─ 已完成 ──► 下载（模拟）
    │         └─► 保存到当前作品 ──► 资产页可见
    │
    └─ 需要新任务 ──► 新建创作 ──► 创作页
```

**保存到作品**默认路径：当前选中作品的 `视频 / 正片镜头` 目录（无作品时会提示先新建或恢复作品）。

---

## 任务从哪来、钱怎么走

```
创作页提交
    ├─ 余额不足 → Toast，不创建任务
    └─ 余额足够
           ├─ 预扣费用（钱包减少）
           ├─ 新建任务，状态「排队中」
           ├─ 记一笔「任务消费」流水
           └─ 跳转任务页

终止（排队中 / 生成中）
    ├─ 状态 → 失败
    └─ 退款入账 + 「任务退款」流水

失败重试
    └─ 状态 → 排队中（不再扣费）

生成成功（后端）
    └─ 状态 → 已完成（原型里多为静态 mock，不自动推进）
```

## 和其他页面的关系

| 页面 | 关系 |
| --- | --- |
| **创作** | 提交后产生任务；页头可跳回创作 |
| **首页概览** | 展示进行中任务摘要，可跳转本页 |
| **资产** | 「保存到当前作品」把成片写入作品工程 |
| **钱包** | 提交预扣、终止退款、失败自动退（文案层面） |
| **管理端任务中心** | 同一批任务在后台可见（用户侧不展示供应商信息） |

主链路：

```
创作 ──提交──► 任务 ──保存──► 资产
         │              │
         └─ 终止/失败 ──┴─► 钱包退款
```

## 侧栏角标规则

| 显示 | 含义 |
| --- | --- |
| 数字（如 `1`） | 当前 `排队中` + `生成中` 任务总数 |
| 无数字 | 没有进行中的任务 |

## 当前实现缺口（若要改产品可讨论）

1. **无任务详情页**：「查看详情」仅 Toast，不能预览成片或看完整参数。  
2. **进度不自动刷新**：mock 里 `生成中` 的进度是静态数，不会自己涨到 100% 并变已完成。  
3. **下载为模拟**，未触发真实文件下载。  
4. **保存**固定进当前作品的 `视频 / 正片镜头`，页面上不能选子目录。  
5. 新任务的工作流、分辨率、时长在 `createTask` 里写死为 H3 / 768P / 15 秒，与创作页表单未完全联动。  
6. 页头说明文案较长，若与广场一样追求极简可去掉。
