# Sub2Video 产品架构与实施顺序

完整菜单、职责、数据边界和技术决策以 [`docs/产品方案总览.md`](./产品方案总览.md) 为准。本文件保留实施清单，供开发任务拆分使用。视觉配方以 [`docs/原型设计/sub2video-client.html`](./原型设计/sub2video-client.html) 和 [`docs/原型设计/sub2video-admin.html`](./原型设计/sub2video-admin.html) 为准；HTML 侧栏里的「创作台 / 作品集」不要搬进 Vue。

## Client Menu

```text
首页概览

创作空间
  创作
  广场
  任务
  资产
  回收站

  钱包

```

场景模板、内容审核 / 风险任务在未实现前隐藏，不展示空页面。

## Non-menu Auth Pages

登录、注册、邮箱验证、忘记密码、重置密码、支付结果、服务条款、隐私政策、账号冻结、维护页和 404 页面独立于侧栏。

## Implementation Order

1. 建立 `design-system.md`
2. 建立 `AGENTS.md` 和 Cursor Rules
3. 建立 Tailwind 令牌与 `cn.ts`
4. 建立 S2V 基础组件
5. 建立客户端和管理端 Layout
6. 迁移客户端首页和创作页
7. 迁移作品、资产、钱包、工单
8. 迁移管理端首页、工作流、任务中心
9. 迁移计费、用户、供应商和运维
10. 加入登录、注册和邮箱验证
11. 加入桌面端和手机端视觉回归

本阶段所有数据使用本地 mock，不接 Go、Redis、MySQL、OSS、支付或真实 Provider。
