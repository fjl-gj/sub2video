# Sub2Video Logo 设计需求说明

> 给外部设计师 / 品牌方使用。  
> 产品内部 UI 规范见 `docs/ui/design-system.md`，产品定位见 `docs/产品方案总览.md`。

---

## 1. 品牌与产品

| 项目 | 说明 |
| --- | --- |
| **品牌英文名** | **Sub2Video**（首选写法：Sub + 2 + Video，中间为数字 2） |
| **中文产品名** | 暂无正式中文品牌名；界面文案为中文，品牌字标以英文为主 |
| **简称** | 内部可用 S2V，**不作为对外主 Logo** |
| **一句话** | 面向创作者的视频生成平台：从灵感、字幕/素材到成片，按作品工程管理资产 |
| **核心隐喻** | Subtitle → Video（字幕 / 素材 → 视频） |

**我们不是什么：** API 网关、模型聚合站、GPU 算力租赁、企业运维后台。不要做成「机房 / 芯片 / 仪表盘」气质。

**典型用户：** 短视频创作者、自媒体、小团队内容制作；会用中文界面，但品牌识别保留英文 Sub2Video 很常见（类似 Notion、Figma 在国内的使用方式）。

---

## 2. Logo 要解决的问题

1. **顶栏识别**：高度约 56px 的浅色顶栏左侧，需要清晰可辨的品牌 Logo（不是单独一个小 App 图标 + 普通文字）。
2. **登录 / 注册**：认证页需要稍大一号的品牌呈现，建立信任感。
3. **Favicon**：浏览器标签 16×16～32×32 仍需可识别（可由主 Logo 衍生图形标，但主交付物应是**完整字标**）。
4. **长期扩展**：未来可能有官网、应用商店、社媒头像；Logo 体系需能延展，而非一次性图标。

---

## 3. 品牌气质（参考方向）

请从中选取 2～3 个主轴，不必全满足：

| 方向 | 关键词 |
| --- | --- |
| 创作者工具 | 专业、顺手、创作台 |
| 视频生成 | 动态、成片、镜头语言（避免廉价「播放键」堆砌） |
| 字幕 → 视频 | 转化、叙事、从文本/素材到画面（可抽象表达，不必字面字幕条） |
| 产品气质 | 克制、现代、偏 Linear / Figma / 剪映专业版，而非游戏化或赛博朋克 |

**避免：**

- 通用「三角形播放键 + 胶片孔」模板感图标
- 过重 3D、霓虹、金属质感
- 与「API / 云计算 / 监控大盘」混淆的视觉
- 过小字号下无法辨认的复杂渐变或细线

## 4. 现有视觉环境（需协调，非硬性照抄）

设计师可提出新方案，但需知产品 UI 已定型，Logo 上线后要和谐共存。

### 4.1 客户端主色（创作者端）

| 用途 | 色值 |
| --- | --- |
| 品牌主色 | `#4F46E5`（Indigo 600） |
| 主色悬停 | `#4338CA` |
| 主色辅助 | `#6366F1` |
| 浅底 / 选中底 | `#EEF2FF` |
| 正文 | `#1E293B` / `#0F172A` |
| 画布背景 | `#F8FAFC`（slate-50） |
| 成功 / 在线 | `#059669`（绿，用于状态，非 Logo 主色） |

### 4.2 管理端

管理端界面强调色为 **Emerald `#059669`**，但 **品牌 Logo 建议与客户端统一**（一套品牌色），不要为管理端单独做第二套 Logo。

### 4.3 字体环境

- **界面中文**：苹方 / 微软雅黑等系统 UI 字体。
- **品牌英文**：产品内拉丁字标计划用 **Inter**（已自托管）；Logo 可使用 Inter 定制字距，或设计师自定义字形，交付时需说明字体授权。
- Logo **不要**依赖中文书法或仅中文图形（除非作为可选副标）。

### 4.4 界面结构参考

- 顶栏：白底、细边框、高度 56px、左侧 Logo + 右侧余额与用户。
- 侧栏：白底 240px，菜单为中文（创作 / 广场 / 任务 / 资产…）。
- 圆角体系：卡片 16px、控件 12px，整体偏紧凑、信息密度高。

可视化原型（仅作布局与气质参考，**不是** Logo 定稿）：

## 5. Logo 体系交付要求

请按 **品牌标识系统** 交付，而非单张 PNG。

### 5.1 必交

| 项目 | 说明 |
| --- | --- |
| **主 Logo（横式字标）** | 推荐：Sub2Video 完整字标；横版，适合顶栏 |
| **图形标（可选但建议）** | 从字标提炼的符号，用于 Favicon / 头像；须与字标同一套语言 |
| **反白版** | 深色背景可用（如未来深色营销页） |
| **单色版** | 黑 / 白，用于印刷或极端场景 |
| **安全空间与最小尺寸** | 标明最小高度（建议顶栏不低于 24px 仍可读） |
| **源文件** | AI / Figma / Sketch + 导出 SVG（矢量优先） |

### 5.2 导出规格建议

| 用途 | 格式 | 备注 |
| --- | --- | --- |
| 前端顶栏 | SVG | 主 Logo，透明底 |
| Favicon | SVG + PNG 32/16 | 图形标即可 |
| 登录页 | SVG 或 2x PNG | 可略大于顶栏 |
| 社媒 / OG | PNG 1200×630 留白版 | 可选 |

### 5.3 命名建议

```text
logo-primary.svg          # 主 Logo 横式
logo-primary-white.svg    # 反白
logo-mark.svg             # 图形标（如有）
favicon.svg
```

## 7. 名称书写规范

| 正确 | 避免 |
| --- | --- |
| Sub2Video | Sub 2 Video（空格断开） |
| Sub2Video | SUB2VIDEO 全大写作为主 Logo（除非设计师有充分理由） |
| Sub2Video | SubToVideo、SubToVid、字幕视频 作为主英文标 |
| 数字「2」 | 字母 z、to、→ 混用（若用连接符需全案统一说明） |

「2」的含义：**Subtitle to Video** 的缩写，可在品牌说明里写一句，Logo 不必字面画出 "to"。

## 8. 可选探索方向（非限制）

设计师可任选或组合，由你们专业判断：

1. **字标为主**：Sub / 2 / Video 三段式字重或颜色区分（2 作为视觉锚点）。
2. **字标 + 抽象符号**：符号表达「素材进入成片」「一帧变多帧」，避免直白播放键。
3. **定制字形**：对 「2」或 「V」做轻微几何处理，形成独有识别。
4. **动态 Logo（二期）**：若考虑加载/生成中动效，请同时给静态主版本。

## 9. 验收标准（建议）

- [ ] 56px 顶栏高度内清晰可读，不与余额按钮、菜单抢戏  
- [ ] 16px Favicon 仍可识别（图形标）  
- [ ] 浅色 UI 背景上对比足够，无需描边也能看清  
- [ ] 不与常见视频 App 图标撞脸  
- [ ] 提供矢量源文件与使用规范（1～2 页 PDF 即可）  
- [ ] 字体可商用或随项目授权
