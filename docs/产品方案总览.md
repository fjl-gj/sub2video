# Sub2Video 产品方案总览

## 产品定位

Sub2Video 是面向创作者的视频生成产品，不是 API 聚合、供应商账户分发或渠道代理平台。创作者只选择创作能力和模型偏好；供应商、成本、密钥、上游工作流和路由策略只存在于管理端与后端。

创作、模型选择、供应商供给、报价和预扣的正式合同见 [创作模式与供应商路由设计](./创作模式与供应商路由设计.md)。该文档优先于任何旧“平台工作流”表述。

### 创作合同

客户端永久只有三种创作模式：

| 模式 | 必填输入 |
| --- | --- |
| 文生视频 | 提示词 |
| 首尾帧生成视频 | 提示词、首帧、尾帧 |
| 多图生成视频 | 提示词、至少一张参考图 |

客户端在模式内可选承运商和模型，或使用“智能推荐”。承运商是模型原厂，例如 MiniMax、火山引擎；模型是 H3、Seedance 2.0 等原厂型号。供应商是采购和调用渠道，永不出现在客户端接口、页面、任务列表或错误信息中。

通用设置为视频时长、输出分辨率、画幅比例和是否自动生成音频。时长是计费数量：`平台每秒售价 × 请求秒数`。只有供给与售价规则同时支持的组合才可估价。已有参考音频上传合同见 [客户端创作](./api/client-create.md)；自动音频不要求参考音频，是否可用以真实执行能力为准。当前整理不扩展音频功能。

客户端先取得目录与能力，再请求只计算、不扣费的 `tasks/estimate`；确认费用后，用完整创作参数和 `Idempotency-Key` 提交。提交阶段服务端重新执行最低成本路由，并在事务内创建订单、扣费和任务。客户端不得提交价格快照、供应商、路由、模型工作流 ID 或成本。

### 客户端职责

| 菜单 | 职责 |
| --- | --- |
| 首页概览 | 查看余额、进行中任务、最近结果和灵感入口 |
| 创作 | 选择固定模式和模型、上传素材、报价并提交任务 |
| 广场 | 浏览编辑型镜头教程，阅读素材要求与提示词，再明确带入创作页；参考照片不作为生成案例 |
| 任务 | 跟踪队列和结果；下载、保存、取消和重新配置创作 |
| 资产 | 管理作品工程下的图片、视频和素材 |
| 回收站 | 恢复或彻底清理已移出的作品 |
| 钱包 | 真实余额、兑换和流水；在线充值未开放，不提供订阅或 API 套餐 |
| 帮助与工单 | 处理生成异常、退款、充值和售前请求 |

## 管理端

```text
首页概览

创作管理
  工作流
  承运商
  供应商

计费管理
  价格审计

任务管理
  任务中心

运营管理
  工单中心

系统
  运维监控
  操作日志
  系统设置
```

| 页面 | 职责 |
| --- | --- |
| 工作流 | 维护三个固定客户端工作流的展示、上架和排序；不能新增第四个工作流，也不绑定模型或上游调用信息 |
| 承运商 | 原厂及其模型的两层列表；模式模型策略声明支持的模式、推荐顺序和默认参数，不拥有平台售价 |
| 供应商 | 供应商、API、workflow 三个 tab；维护模型绑定、执行配置、能力、健康和采购成本，执行列表按承运商/模型筛选 |
| 价格审计 | 按创作模式、分辨率、自动音频维护平台售价和版本；历史模型价格仅供查看，新流程不使用 |
| 任务中心 | 查询任务的模式、模型、供给快照、上游状态和退款；失败重试必须重新预估并创建新任务 |

官方渠道和第三方渠道都是“供应商”。供应商成本属于供应商供给，不能写在模型或平台售价规则中。

## 核心数据边界

```text
创作模式 ─ 模式模型策略 ─ 模型 ─ 承运商
创作模式 ─ 平台售价规则（模式 × 分辨率 × 自动音频 × 版本）
供应商 ─ 模型绑定 ─ 执行配置（API / workflow）─ 供应商成本规则
预估请求 ─ 当前能力与售价计算（不持久化报价）
提交请求 ─ 幂等检查 ─ 重新路由 ─ 订单、任务快照、钱包扣费与流水
```

任务创建先在事务内按用户与请求 ID 检查原订单；已存在则返回原订单和任务，不再路由。首次提交重新路由、锁定钱包并创建任务、订单、扣款和流水；执行配置、供应商成本和平台售价写入不可变快照。不生成 quoteId，不比较预估与提交结果。提交后调价或供给变更不影响已创建任务，Worker 不会自动换模型或供应商。明确失败按幂等退款规则处理，提交结果不确定时进入待核对状态。

## 技术方案

前端使用 Vue 3、TypeScript、Vite、Vue Router、Pinia、Tailwind CSS、Reka UI、`tailwind-variants`、`clsx`、`tailwind-merge` 和 Lucide Vue。客户端与管理端独立 Layout 和路由命名空间，共享设计令牌与基础组件。

后端已使用 Go + Gin + PostgreSQL + pgx，提供 JWT 身份验证、钱包、素材/作品工程、供应商供给、报价和任务 Worker。Redis 用于服务连接与异步基础设施；对象存储支持 MinIO/COS，用于可被上游访问的素材与结果。供应商密钥加密存储，管理端仅显示“已配置”。

## UI 修改边界

视觉配方以 [设计系统](./ui/design-system.md)、[商业工作台设计](./ui/studio-redesign.md) 和 [创作者五页主链路](./ui/creator-journey.md) 为准；原型设计目录保留为历史参考。菜单、路由和作品/资产对象模型以本文件为准；不要将 HTML 中的“创作台/作品集”复制到 Vue。

公开产品入口为 `/`，镜头教程为 `/guides/:id`，匿名访问不读取私有任务与资产。原登录后首页保留 `/app/overview`。教程通过 `/app/create?guide=...&shot=...` 带入受信任的编辑内容，已有草稿需用户明确应用后才替换。参数以实时创作能力为准，教程不携带售价或内部执行信息。

创建任务成功后进入 `/app/works/:id`；结果预览、下载与保存都使用真实任务接口。保存时明确选择作品，成功后进入 `/app/assets?project=...&folder=...`，刷新可恢复目录。此流程复用已有作品与任务模型，不表示具有整片自动剪辑、镜头进度持久化或人物一致性能力。

```text
全局令牌 → shared/styles / tailwind.config.ts
共享组件 → shared/ui
领域交互 → features / entities
页面布局 → widgets / pages
```
