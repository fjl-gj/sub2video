# Sub2Video 产品方案总览

## 产品定位

Sub2Video 是面向创作者的视频生成产品，不是 API 聚合、供应商账户分发或渠道代理平台。创作者只选择创作能力和模型偏好；供应商、成本、密钥、上游工作流和路由策略只存在于管理端与后端。

创作、模型选择、供应商供给、报价和预扣的正式合同见 [创作模式与供应商路由设计](./创作模式与供应商路由设计.md)。该文档优先于任何旧“平台工作流”表述。

### 创作合同

客户端永久只有三种创作模式：

| 模式 | 必填输入 |
| --- | --- |
| 文生视频 | 提示词 |
| 首尾帧生成视频 | 提示词、首帧、尾帧 |
| 多图生成视频 | 提示词、至少一张参考图 |

客户端在模式内可选承运商和模型，或使用“智能推荐”。承运商是模型原厂，例如 MiniMax、火山引擎；模型是 H3、Seedance 2.0 等原厂型号。供应商是采购和调用渠道，永不出现在客户端接口、页面、任务列表或错误信息中。

通用设置为视频时长、输出分辨率、画幅比例和是否自动生成音频。时长是计费数量：`平台每秒售价 × 请求秒数`。只有供给与售价规则同时支持的组合才可报价。首期“音频”只表示模型自动生成音频，不接收参考音频。

客户端通过短时、一次性的服务器报价创建任务：先取得目录与能力，再请求 `quoteId`，最后用 `quoteId`、提示词和素材引用提交。客户端不得提交价格快照、供应商、路由、模型工作流 ID 或成本。

### 客户端职责

| 菜单 | 职责 |
| --- | --- |
| 首页概览 | 查看余额、进行中任务、最近结果和灵感入口 |
| 创作 | 选择固定模式和模型、上传素材、报价并提交任务 |
| 广场 | 浏览官方场景和预设提示词，一键带入创作页 |
| 任务 | 跟踪队列和结果；下载、保存、取消和重新配置创作 |
| 资产 | 管理作品工程下的图片、视频和素材 |
| 回收站 | 恢复或彻底清理已移出的作品 |
| 钱包 | 余额、充值、兑换和流水；不提供订阅或 API 套餐 |
| 帮助与工单 | 处理生成异常、退款、充值和售前请求 |

## 管理端

```text
首页概览

创作管理
  工作流
  承运商与模型
  供应商与模型

计费管理
  价格审计

任务管理
  任务中心

运营管理
  工单中心

系统
  运维监控
  操作日志
  系统设置
```

| 页面 | 职责 |
| --- | --- |
| 工作流 | 维护三个固定客户端工作流的展示、上架和排序；不能新增第四个工作流，也不绑定模型或上游调用信息 |
| 承运商与模型 | 承运商是模型原厂，模型归属承运商；模型配置声明其支持的工作流、智能推荐顺序、默认参数和对客售价 |
| 供应商与模型 | 维护供应商调用地址和凭据，以及供应商模型执行配置、上游执行标识、实际能力、健康状态和采购成本 |
| 价格审计 | 只读核查当前平台售价和版本；售价的唯一编辑入口是对应模型的模型配置 |
| 任务中心 | 查询任务的模式、模型、供给快照、上游状态和退款；失败重试必须创建新报价和新任务 |

官方渠道和第三方渠道都是“供应商”。供应商成本属于供应商供给，不能写在模型或平台售价规则中。

## 核心数据边界

```text
固定工作流 ─ 模型配置 ─ 模型 ─ 承运商
                  │
                  ├─ 平台售价规则（工作流 × 模型 × 分辨率 × 自动音频）
                  └─ 供应商模型执行配置 ─ 供应商 ─ 供应商成本规则
用户请求 ─ 报价快照 ─ 任务执行/价格/供给快照 ─ 钱包流水
```

任务创建在同一事务中锁定报价和钱包，创建任务、扣款、写流水、消费报价。供给、采购成本或售价变更后，未使用的旧报价失效；已创建任务继续使用创建时的快照，Worker 不会自动换模型或供应商。上游终态失败时全额退款。

## 技术方案

前端使用 Vue 3、TypeScript、Vite、Vue Router、Pinia、Tailwind CSS、Reka UI、`tailwind-variants`、`clsx`、`tailwind-merge` 和 Lucide Vue。客户端与管理端独立 Layout 和路由命名空间，共享设计令牌与基础组件。

后端已使用 Go + Gin + PostgreSQL + pgx，提供 JWT 身份验证、钱包、素材/作品工程、供应商供给、报价和任务 Worker。Redis 用于服务连接与异步基础设施；对象存储支持 MinIO/COS，用于可被上游访问的素材与结果。供应商密钥加密存储，管理端仅显示“已配置”。
