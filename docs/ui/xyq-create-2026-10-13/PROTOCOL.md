# 页面改版 · 后端接口协议影响

日期：2026-10-13。对照现有 `docs/api/client-*.md` 与创作合同。  
结论先看：**本轮视觉/交互改版，绝大多数不改后端协议；唯一需要单独立项的是「真对话助手」若要上线。**

## 1. 不需要改协议（前端呈现即可）

| 页面变化 | 原因 |
| --- | --- |
| 官网精简为首屏影像 + 三种方式 | 公开页；模式说明可用静态文案，或只读已有 `GET /api/v1/client/create/catalog` 的 `modes[]`（匿名策略若已有则沿用） |
| 官网/登录注册全幅视频背景 | 静态资源（`creator-studio-loop.mp4` 等），无 API |
| 创作页小云雀式中央输入盒、底栏芯片、偏好弹层 | 仍调用现有 `catalog` → `options` → `estimate` → 创建任务；字段不变 |
| 「当前采用的镜头描述」可编辑稿 | 客户端本地草稿；提交时仍只传最终 `prompt` |
| 发消息整理描述不扣费 | 前端行为；不调扣费接口即符合合同 |
| `@` 引用素材库 / 本地上传 | 可复用现有上传与资产引用：`sourceMeta.*.type = upload \| asset` + `id` |
| 首尾帧/多图槽位、缺必填禁用 | 现有模式输入合同已约束；估价前校验在客户端 + 服务端 |
| 概览/钱包/帮助/资料浅色壳 | 仍用现有 overview / wallet / tickets / profile 接口；UI 重组不改字段 |
| 登录注册表单布局、密码显隐 | 纯 UI；无第三方登录 |
| 注册「邮箱验证码」交互示意 | 若认证合同已有发码/校验接口则沿用；设计稿仅前端倒计时示意，**不另造字段** |

## 2. 建议确认、但默认「零协议变更」

| 点 | 说明 | 建议 |
| --- | --- | --- |
| 官网是否拉 `catalog` | 用于三模式上下架/文案 | 若公开目录已存在则用；否则静态三模式即可，**不要**为此新建公开 API |
| 概览「三模式入口」可用性 | 应用 `catalog.modes[].enabled` 或 options 失败态 | 沿用现有；不可用时入口禁用并诚实提示 |
| 智能推荐 | `options` / `estimate` 省略 `modelId` | 已有合同，弹层默认「智能推荐」即可 |
| 创作偏好弹层参数 | 时长/分辨率/画幅/音频来自 `options` | **禁止**前端写死全量 10s/1080P/音频 |

## 3. 若产品要「真对话 Agent」——才需要新协议（本设计稿未实现）

当前设计稿里的对话是 **本地示意**（或仅改写本地采用稿）。若要变成服务端助手：

| 候选能力 | 协议方向（需单独评审） | 边界 |
| --- | --- | --- |
| 润色/整理提示词 | 例如 `POST /api/v1/client/create/prompt-assist`：入参草稿文案与模式；出参建议文案；**不计费或不走任务钱包** | 建议必须「明确采用」才写入采用稿；不得自动 `estimate` / 创建任务 |
| 多轮会话持久化 | 会话 id、消息列表、与镜头草稿关联 | 可选；MVP 可不持久化 |
| 费用 | 若助手本身计费，需独立计价规则 | **不得**与视频生成估价混写 |

未立项前：**不要**改 `tasks/estimate` 或创建任务 body。

## 4. 明确禁止写进客户端协议的内容（不变）

以下仍不得出现在任何客户端响应/错误/任务字段：

- 供应商名称、成本、采购价  
- 上游 workflow / API 编码、路由细节  
- 客户端提交价格快照、quoteId 锁价  

计费仍为：`平台每秒售价 × 秒数`；先 `estimate` 再提交；提交服务端重新路由并扣费。

## 5. 落地时的接口清单（按现有文档）

创作主链路（不变）：

```text
GET  /api/v1/client/create/catalog
GET  /api/v1/client/create/options?modeId=&modelId?
POST /api/v1/client/tasks/estimate
POST /api/v1/client/tasks   (+ Idempotency-Key)
(+ 既有图片/参考音频上传)
```

账户与其它页（不变）：

```text
GET  /api/v1/client/overview
钱包 / 工单 / 资料 / 认证 既有接口
```

## 6. 一句话给研发排期

- **P0 前端改版**：官网、认证视频底、创作壳 —— **0 后端变更**。  
- **P1**：若要真·提示词助手 —— **新增独立 assist 合同**，与生成扣费隔离。  
- **不做**：为小云雀 UI 去改 estimate/submit 语义或暴露供应商。
