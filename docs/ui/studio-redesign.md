# Sub2Video 商业工作台改版

日期：2026-09-25。分支：codex/commercial-studio-redesign。起点：a479c33。

## 研究范围与证据

本次通过内置浏览器查看用户已打开的三个站点：

- [小云雀](https://www.xiaoyunque.com/home)：首页、视频生成入口、模型与偏好弹层。
- [可灵 AI](https://klingai.com/app/)：创意圈、视频生成工作区及历史结果展示。
- [有戏 AI](https://youxi.fullpeace.net/)：首页、项目/资产导航、作品案例信息卡。

只观察页面和展开已有入口，没有在参考平台上传文件、提交生成、充值或修改项目。未复制参考平台作品、品牌图标、文案或私有数据。最初尝试即梦时连接失败；用户随后指定小云雀，最终以以上三个实看页面为依据。

| 观察维度 | 小云雀 | 可灵 AI | 有戏 AI | Sub2Video 决策 |
| --- | --- | --- | --- | --- |
| 创作入口 | 中央描述输入，工具快捷入口 | 紧凑工具导航，输入与结果并排 | 创作、项目、资产分工清楚 | 保留三个模式；首页直达，创作页以输入为第一任务 |
| 参数组织 | 模型与偏好分区，按需展开 | 素材/描述集中，底部参数与生成 | 能力与项目相关联 | 明确承运商/模型标签，六类参数成组，费用紧邻提交 |
| 内容密度 | 大输入区，下方推荐内容 | 图像瀑布流、真实结果占较大面积 | 项目案例封面与简短元信息 | 用真实成片、素材和任务形成丰富度，不堆指标卡 |
| 视觉容器 | 深色背景、低对比容器 | 深色工作区、收敛边框 | 深色卡片、明确导航层级 | 统一深炭灰与暖琥珀；管理端用同源浅色令牌 |
| 反馈 | 费用/模型偏好靠近输入 | 生成历史与结果可直接查看 | 项目与资产提供创作连续性 | 明确加载、失败、空态、交付状态，最近结果可追溯 |

三者的营销活动、订阅、Agent、短剧分镜等功能不属于本次范围。参考的是内容层级和交互组织，不照搬它们的业务与配色。

## 设计原则

1. 主操作明确：每个工作区有一个主要动作，余额、空间、设置是辅助信息。
2. 素材与结果优先：真实图片和视频构成主视觉；没有内容时诚实提示下一步。
3. 一套语言：字族、8px 控件圆角、12px 面板圆角、品牌色、状态色、间距和焦点规则一致。
4. 页面完整但不虚构：真实任务、结果和资产可串联，不添加无行为按钮与虚假记录。
5. 移动端重新排序：先输入后预览，保留可见标签和容易触达的生成动作。

## 页面落地

### 客户端框架

200px 导航、64px 顶栏、中性深色画布。统一字标、暖色主按钮、语义状态徽章。顶栏显示当前位置、创作余额与用户菜单。手机使用56px顶栏、底部导航与可关闭抽屉。

### 创作

桌面左侧约380px：模式、素材、画面描述、承运商/模型/时长/分辨率/画幅/音频、预估与提交。右侧：真实参考图或已交付视频、详情入口、最近任务。手机按输入优先顺序排列。

移除雨滴 canvas、模拟时间码与假播放。估价区区分等待设置、计算中、可用金额、失败/重试。参数变更后的旧响应不得覆盖最新参数。保持现有参数与 Idempotency-Key 提交合同。

### 首页和资产

首页提供三模式入口（可用性来自服务端）、最近成片大预览、进行中任务以及紧凑用量信息。任务详情或视频读取失败时明确说明，不用示例媒体替换失败结果。

项目卡保留作品/文件夹/文件的既有数据模型和操作。没有真实封面时使用清楚的文件夹呈现，不使用示例作品填充。

### 管理端

同源浅色主题、紧凑导航和表格；承运商与供应商去掉重复指标卡。分页与弹窗编辑保留。窄屏表格在容器内横向滚动，不把编码和列名压成竖排。

### 统一性处理

- shared/ui 管共享控件与框架配方；features 管业务布局和反馈。
- 首页与创作 CSS 分别限定根作用域，防止切换页面后样式相互覆盖。
- 文档根节点绑定当前 surface，确保传送到 body 的弹窗也继承正确主题。
- 图片遮罩使用独立深色 token，避免深色主题的浅色 ink 变成白色遮罩。
- 历史 HTML 原型保留为历史参考，当前视觉规范以 design-system.md 与新设计稿为准。

## 验证边界

要求 lint、typecheck、生产构建、UI合同、桌面/手机和视觉基线通过。新增合同重点验证估价失败、请求乱序、模式入口、真实媒体错误和窄屏布局。

本次是前端设计与交互完善，不修改后端、迁移、供应商、支付或财务规则。Mock UI 测试不代表数据库/Worker/真实供应商 UAT 通过；不执行收费生成任务，不部署107。
