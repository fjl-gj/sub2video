## 风格与内容

沿用 `docs/ui/design-system.md` 的深灰、暖金、思源黑体与 Inter，不建立另一套设计系统。参考小米的统一对齐线、明确层次与克制表达；媒体负责视觉丰富度，界面不添加霓虹、发光、装饰徽章或虚构成绩。

首屏使用现有登录/注册视频的同一封面，背景独立铺满屏幕，不放进限宽容器或圆角卡片。桌面标题居中、人物偏左；手机单独裁切并将文案放在下方，保留面部。正文内容有安全边距；背景铺满不等于正文贴边。

| 区域 | 内容与作用 |
| --- | --- |
| 导航与首屏 | 品牌、创作方式、镜头教程、如何开始；一个主要创作入口和一个教程入口 |
| 三种创作方式 | 文生视频、首尾帧、多图；解释所需输入和用途 |
| 镜头教程 | 海岸来信、产品光影、场景转场；使用构图参考，不伪装成客户作品 |
| 使用流程 | 准备素材 → 选择参数并估价 → 提交并查看任务 → 下载或保存 |
| 常见问题 | 素材、估价、任务失败处理、完整短片仍需外部剪辑 |
| 页脚 | 教程、帮助、条款和隐私入口，无重复宣传口号 |

没有公开价格、客户数、节省比例、生成时效保证、已开放支付或一键完成短剧等承诺。模型参数以真实创作目录为准。没有恢复此前要求删除的品牌影像署名、冗余标语与装饰 SVG。

主体字体为本地 Source Han Sans SC，字标为本地 Inter。正文以 400 为主，标题与主要操作以 500 为主，不堆叠粗体。主色 `#e8b981` 只强调主要操作和少量引导信息；正文与辅助文字使用现有中性色。

小屏设计以可操作为先：图片不拉伸，按钮可换行，文本不依赖悬停，所有链接有键盘焦点。短高度规则已加入 HTML；320、768、1024、1920 和短屏实际浏览器检查仍需补做，不能把存在 CSS 断点当作已经验收。

## 检查记录

已使用内置浏览器查看 1440 × 900 桌面和 390 × 844 手机，检查人物裁切、标题与操作位置，并导出桌面完整页。DOM 检查确认七张图片加载成功，390px 视口的 `scrollWidth` 与 `clientWidth` 都为 375px，没有横向溢出；剩余宽度为桌面浏览器滚动条区域。

只读复核发现固定 900/844 最小高度会导致短屏 CTA 出屏，已改为实际 100svh 并补充短高度布局规则。手机截图在修改后导出；尚未实际浏览器验证短屏规则。

后续浏览器访问本地预览地址被权限策略拒绝，已停止浏览器操作。未完成手机整页导出、其他尺寸审图以及静态稿锚点/FAQ 的逐项交互验收。没有使用其他浏览器或无头浏览器绕过限制。

这是设计交付，未运行产品 lint、typecheck、Go 或 Playwright 测试；未改产品代码，已有生产测试结果不作为本稿交互验收证据。`git diff --check`、两份新增文本的 `git diff --no-index --check` 已通过，四张导出图已确认是实际 PNG，桌面/手机总览已人工审图。本轮临时生成器已删除；设计资料与本地素材保留在本目录。
