## 如何收敛

| 上一版问题 | 第二版处理 |
| --- | --- |
| 首页连续展示模式、教程、流程和 FAQ，信息竞争 | 首屏 → 一个产品展示 → 页脚；教程与帮助留在导航 |
| 三组卡片重复标题、说明、要求与创作按钮 | 三种模式在一处切换，一次只显示一句说明 |
| 12–15px 的辅助信息过多 | 正文 18–20px，辅助文字 16px；不再连续堆叠备注 |
| 首屏口号、解释与多个入口并列 | 一个说明文字/图片创作能力的标题，一个主要创作操作 |
| 海岸、森林、商品与动漫混用 | 使用同一组用户提供的动漫品牌影像 |
| 图片需要反复标注防止误认为交付结果 | 产品展示保留“创作界面示意”和“参考画面”，不展示假成功、假价格或假客户案例 |

商业表达的重点是让人立即理解“可以用什么创作、从哪里开始、产品长什么样”。不通过客户数字、案例、支付能力或完成一整部短剧等未验证承诺填满首页。

延续现有 Source Han Sans SC + Inter、中性色与暖金色，不创建新的设计系统。本次精简的信息架构与放大的官网字号已经用户确认，同步收敛至 docs/ui/design-system.md；本地实现与 107 发布分开验收。

首屏影像全幅 cover，零外边距、边框和圆角；桌面与手机人物裁切分别沿用 58% 和 30% 水平焦点。主要内容共用一条对齐线，桌面32px边距、手机16px；宽屏最大1760px。正文结构不靠大面积空卡片填充。

正文的产品展示仅有一个12px圆角容器，顶部模式切换采用下划线区分选中项。桌面为左输入、右参考画面；手机保留模式、一句说明与极简素材区，然后显示参考画面，隐藏参数与次级按钮。文生视频展示画面描述和一行说明，图片模式展示两张小素材。实际创作页仍应输入在前，这份营销页示意不改变其业务合同。

首屏、产品示意均使用品牌素材，不是客户作品或供应商交付证据。原生设计图使用项目现有字体，缺字按现有系统后备字体思路使用微软雅黑；已审图修复缺字方框与标点基线问题。
