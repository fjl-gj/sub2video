# 登录与注册入口 · 2026-09-26

本次将此前居中卡片式入口改为影像与表单并列的创作者产品入口，沿用公开首页和工作台的深色中性背景、暖金色主操作、字体和品牌标识。视觉丰富度来自影像，不增加发光装饰、假用户数量、假登录方式或未实现的功能。

## 页面与素材

- 桌面：左侧大幅影像、品牌主张和三种既有创作模式；右侧登录或注册表单。两个页面共用外壳，切换时不重新开始播放。
- 手机：900px 以下改为短影像区在上、表单在下；最小支持 320px。视频不抢占移动端带宽，点击才加载。
- 媒体：本地 `public/brand/auth/iceland-coast.webm`（约 2.1 MiB）与 JPG 封面（约 114 KiB），静音循环，可暂停；减少动态效果或节流时只展示封面。播放失败保留封面，封面也失败时保留品牌文案与表单。
- 来源：Alexander Grebenkov 的冰岛海岸实拍，CC BY 3.0；页面可见署名和授权链接，详情见 `frontend/public/brand/auth/ATTRIBUTION.md`。这不是 Sub2Video 生成案例，也未取用任何用户私有作品。未来自有宣传片可以替换此素材。

## 交互与真实性

登录支持 Enter 提交、密码显隐和密码管理器，失败时保留输入并允许重试，移除没有实际行为的“记住我”。公开设置关闭找回密码或注册时，不再显示可操作入口。

注册先读取真实公开设置。加载失败显示重试，关闭注册显示明确状态；未确认设置时不允许提交。邮箱验证码由后端开关决定，修改邮箱清空旧验证码与对应提示。必须主动勾选条款，且符合密码和验证码要求才能注册。保留原有安全回跳、余额同步与邮箱验证接口。没有新增第三方登录或支付合同。

## 会话可靠性

首页概览、钱包和创作目录同时遇到 401 时，共享一次续期请求；迟到的旧响应不得清除新凭证、恢复已退出账号或覆盖后来登录的账号。任务重放使用原始参数和幂等键，单个请求只重放一次。网络错误与 5xx 保留会话，明确失效才清理登录并回到安全的内部目的地。

退出立即离开私有页面，服务端撤销失败有独立提示。修复用户菜单遮罩挡住退出按钮的问题。增加浏览器 `s2v_auth_session` 记录，将令牌对与会话身份一并保存；兼容导入原有两个令牌键。没有数据库迁移、任务数据修改或账本改动。

跨标签页通过 storage 同步状态，并在支持 Web Locks 的 HTTPS/localhost 环境协调续期。**107 普通 HTTP 下不能保证多标签同时续期互斥**，不能将 localhost 测试结果表述为该场景已通过。公开部署应使用 HTTPS；若必须支持 HTTP 多标签互斥，需要后续独立实现和验证。
